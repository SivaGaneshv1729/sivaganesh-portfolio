## ✨ Key Features

- **Cinematic Multilingual Preloader**: A professional entry experience featuring "Hello" in 8+ languages with a smooth blur-and-fade transition.
- **Dynamic Hero Section**: Interactive role-switching animation with a stable, flicker-free layout.
- **Scroll-Linked Project Visuals**: A custom-engineered "locked" scroll-jack layout that reveals project details alongside high-fidelity UI mockups.
- **Glassmorphic Design**: Modern aesthetic using CSS backdrops, subtle gradients, and sophisticated micro-animations.
- **Responsive & Theme-Ready**: Fully optimized for mobile, tablet, and desktop with integrated light/dark mode support.

## 🛠️ Tech Stack

- **Core**: HTML5, Vanilla CSS3, Modern JavaScript (ES6+)
- **Icons**: Devicon, Font Awesome
- **Design Concepts**: BEM Methodology, Glassmorphism, Responsive Grid Systems
- **Deployment**: Cloudflare Pages

## 🔧 Installation & Local Setup

To run this project locally:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SivaGaneshv1729/Portfolio-Web.git
   ```
2. **Navigate to the directory:**
   ```bash
   cd Portfolio-Web
   ```
3. **Open `index.html`** in your preferred browser or use a live server extension in VS Code.

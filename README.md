# Personal Portfolio - T Siva Ganesh Vemula

A modern, responsive personal portfolio website built from scratch to showcase my journey as a software engineer.

## 🚀 Live Demo
**[sivaganeshv.pages.dev](https://sivaganeshv.pages.dev/)**

## ✨ Key Features
- **Fully Responsive**: Optimized for mobile, tablet, and desktop viewports.
- **Parallax Scrolling**: Subtle depth effects implemented with Framer Motion.
- **On-Scroll Animations**: Smooth entrance animations for all major sections.
- **Modern UI**: Built with a glassmorphic aesthetic and Tailwind CSS.
- **Accessibility**: Includes support for `prefers-reduced-motion`.

## 🛠️ Tech Stack
- **Framework**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Deployment**: [Cloudflare Pages](https://pages.cloudflare.com/)

## 🔧 Installation & Local Setup

1. **Clone the repository:**
   ```bash
   git clone https://github.com/SivaGaneshv1729/Portfolio-Web.git
   ```
2. **Navigate to the directory:**
   ```bash
   cd Portfolio-Web
   ```
3. **Install dependencies:**
   ```bash
   npm install
   ```
4. **Run local development server:**
   ```bash
   npm run dev
   ```
5. **Build for production:**
   ```bash
   npm run build
   ```
